# MeanGreen Marketplace App

## CSCE 3444 - Software Engineering

**Team:** Eagle Coders

MeanGreen Marketplace is a marketplace application designed for current University of North Texas students. The app allows students to buy, sell, or give away items within the UNT community.

## Main Features

- User Sign Up, Login, and Logout
- User Profile
- Browse marketplace listings
- Search listings by keyword or course code
- Filter listings by category, price, condition, and location
- View listing details
- Create and manage listings
- List items as free or for sale
- In-app messaging between buyers and sellers
- Favorites / saved listings
- Listing status: Available, Pending, or Sold
- Notifications
- Report users or listings

## Project Status

The project is currently in the implementation phase and will be developed using an Agile methodology across two sprints.

- **Sprint 1:** Core marketplace functionality
- **Sprint 2:** Additional features, integration, testing, and final improvements
